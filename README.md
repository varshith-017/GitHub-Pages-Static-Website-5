 🚀 Task 6: Host a Static Website with GitHub Pages

📌 Project Overview
This project demonstrates how to create and deploy a static portfolio website using **GitHub Pages**. The website is developed using HTML5 and CSS3 and hosted for free through GitHub.

 💻 How to Run Locally

1. Clone the repository:

```bash
git clone https://github.com/varshith-017/GitHub-Pages-Static-Website-5.git
```

2. Open the project folder.
3. Open `index.html` in your web browser.

 🚀 Deployment Using GitHub Pages

1. Create a GitHub repository.
2. Upload the HTML and CSS files.
3. Open repository Settings.
4. Navigate to Pages.
5. Select **Deploy from a branch**.
6. Choose `main` branch.
7. Select `/ (root)` folder.
8. Click Save.
9. Wait for GitHub Pages to publish the website.
